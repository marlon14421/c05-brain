# Obsidian setup

Öffne den Ordner `Cybersecurity Knowledge Base` als Vault oder verschiebe seinen Inhalt in einen bestehenden Vault. Die Startseite liegt unter `00 Start Here/Home.md`. Jede Wissensnotiz enthält YAML-Metadaten und eine Quelle. Indizes sind als Obsidian-Wikilinks angelegt.

Die Einträge wurden aus den verlinkten MITRE-Datensätzen erzeugt; ergänzende defensive Leitfäden sind redaktionelle Orientierung, keine Rechts- oder Sicherheitsgarantie.
